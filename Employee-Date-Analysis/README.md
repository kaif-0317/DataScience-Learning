# Employee Data Analysis

## Project Overview

This project analyzes employee data using Python, Pandas, NumPy, and Matplotlib.

## Dataset

The dataset contains employee information including:

* Name
* Age
* Department
* Salary

## Tasks Completed

* Data loading
* Data cleaning
* Handling missing values
* Removing duplicate records
* Data filtering
* Data analysis
* Department-wise employee analysis
* Data visualization
* Business insights

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Visualizations

The project includes charts for employee department distribution and other data insights.

## Key Insights

The analysis identifies:

* Total number of employees
* Total salary paid
* Average salary
* Highest salary
* Lowest salary
* Employees by department

## Conclusion

This project demonstrates the complete process of cleaning, analyzing, and visualizing employee data using Python. It helped develop practical skills in data analysis and extracting meaningful business insights.
